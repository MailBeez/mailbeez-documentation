[doc-callout type="note" title="Earlier MailBeez versions"]
To review opt-outs and blocks in V5, open [Contacts](/mailbeez-results/contacts). [Browse the legacy reference](/legacy).
[/doc-callout]

Look up the recipient address when an expected email is missing. Check whether the block names one module or applies to all modules. If the recipient has requested a change, use [Advanced Opt-Out with Admin](/configbeez/config_block_admin) to manage the preference.

If the customer still receives other mail, a module-level preference can explain the difference. Read its scope before assuming the opt-out was lost.
