Match the question to the older report. Use the event log for a processing run, the tracking report for a single email and the opt-out list for a recipient block. For current campaign reports, see [MailBeez](/mailbeez-results).

Keep the order number, recipient address and approximate time nearby. Each helps narrow the search in a different report when you follow a single message.
