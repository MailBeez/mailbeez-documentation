Follow a referral from the invitation to the friend’s order and the buyer’s reward. If an expected order is missing, compare its status with the qualifying status set in [Coupon Referral Honey](/mailbeez/coupon_referral_honey).

A shared invitation, a referred order and an earned reward are separate points in the programme. Find the last recorded point before investigating what happened next.
