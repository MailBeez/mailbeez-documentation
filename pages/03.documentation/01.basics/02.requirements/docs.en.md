Choose your platform under [Installation](/basics/installation). Shopify, WooCommerce, JTL-Shop and Shopware use the planned hosted connection. MailBeez Services checks the connector requirements with you. The PHP versions below apply when MailBeez runs on your shop server.

## Running MailBeez on your shop server

You need access to your shop files and administration to install MailBeez.

Check the version of PHP that runs the storefront. A hosting account can offer several PHP versions, and the one assigned to the shop determines which code it can run.

MailBeez V5 supports PHP 7.4 and PHP 8.0 through 8.6. Choose a version supported by your shop, extensions and host as well. For an older installation, use the requirements for its original package in the [legacy reference](/legacy).
