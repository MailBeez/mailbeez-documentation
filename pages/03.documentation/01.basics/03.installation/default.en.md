[doc-details title="Share an installation guide as a MailBeez partner"]

Copy the address of the guide for your customer’s shop and add `?a=YOUR_CODE`. Replace `YOUR_CODE` with your assigned partner code. For example, use `https://guide.mailbeez.com/basics/installation?a=YOUR_CODE`. If the address already contains `?`, append `&a=YOUR_CODE` before any `#` section link.

When your customer opens the link, the documentation remembers a recognized code in that browser tab and removes it from the address bar. The code travels with documentation links and MailBeez download links, including after a language switch. To check it, copy a download link from the guide and look for `a=YOUR_CODE` in its address.

[/doc-details]
