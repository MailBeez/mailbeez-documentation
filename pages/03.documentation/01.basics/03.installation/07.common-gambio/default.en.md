[doc-callout type="note" title="Installation for earlier shop releases"]
Check the version in your shop admin. For a different release, look under [Installation](/basics/installation) or in the [legacy reference](/legacy).
[/doc-callout]

Find the GX release in the shop administration before choosing an installer.

The release determines both how you get the integration and where you open it. Look up the full GX version if the menu in a guide differs from yours.

- **From GX 2.5**<br>
  Use the bundled module in the [Gambio GX 2.5+](/basics/installation/basic-installation-gambio-gx-25) guide.
- **GX 2.3.x and 2.4.x**<br>
  Use the [Gambio GX 2.3+](/basics/installation/basic-installation-gambio-gx-23) admin entry.
- **Earlier versions**<br>
  Use the integration files for [Gambio GX 1.x](/basics/installation/basic-installation-gambio) or [Gambio GX 2.x](/basics/installation/basic-installation-gambio-gx-2).
