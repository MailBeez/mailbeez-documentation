[doc-callout type="note" title="Frühere MailBeez-Versionen"]
[Zur Referenz für ältere Versionen](/legacy).
[/doc-callout]

Suche in einer älteren Shopinstallation unter `mailhive/`. Die folgende Übersicht zeigt, wo du die Dateien für deine Aufgabe findest.

Grenze die Suche danach ein, was sich geändert hat. Bei einer einzelnen Kampagne beginnst du im Modulordner. Gemeinsame Funktionen können mehrere Module betreffen.

| Verzeichnis | Inhalt |
| --- | --- |
| <span id="common"></span>`common/` | Dateien, die mehrere Module gemeinsam nutzen. |
| <span id="common-template-c"></span>`common/templates_c/` | Erzeugte Smarty- und Anwendungscaches. Ändere für ein anderes Layout die Quellvorlage. |
| <span id="configbeez"></span>`configbeez/` | Konfigurationsmodule. Sichtbare Module erscheinen im Konfigurationsregister. |
| <span id="dashboardbeez"></span>`dashboardbeez/` | Widgets, die nach der Installation im früheren Dashboard zur Verfügung stehen. |
| <span id="filterbeez"></span>`filterbeez/` | Filter und Hilfsmodule für Empfängerauswahl und Nachrichteninhalt. |
| <span id="gui-deprecated"></span>`gui/` | Frühere Oberflächendateien für den Abmeldedialog. |
| <span id="images"></span>`images/` | Gemeinsame Bilder, etwa das Logo im E-Mail-Kopfbereich. |
| <span id="includes"></span>`includes/` | Integrationsdateien, die Shop oder Administration einbinden. |
| <span id="install"></span>`install/` | Installationsdateien für Shops auf Basis von xt:Commerce. |
| <span id="mailbeez"></span>`mailbeez/` | Kampagnenmodule für die frühere Modulverwaltung. |
| <span id="reportbeez"></span>`reportbeez/` | Module für die früheren Berichte. |
