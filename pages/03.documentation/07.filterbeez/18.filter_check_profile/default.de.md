[doc-callout type="note" title="Frühere MailBeez-Versionen"]
In V5 kannst du unter [Listen und Segmente](/contacts/lists-segments) eine Empfängerauswahl zusammenstellen. [Zur Referenz für ältere Versionen](/legacy).
[/doc-callout]

Der frühere Profilfilter nutzte Tags aus [Profilierungs-System](/configbeez/common_services/config_profiling_engine) zur Auswahl von Kunden oder Bestellungen für ein Modul. So konnte eine Regel Bestellungen mit einem bestimmten Produkt-Tag von einer Erinnerung ausschließen. Prüfe dafür den installierten Entwicklungsstand.

Formuliere die Zielgruppe zuerst in eigenen Worten, etwa Kunden, die eine bestimmte Produktreihe gekauft haben, eine andere aber noch nie. So lässt sich die Tag-Regel leichter einordnen.
