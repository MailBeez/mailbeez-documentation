Find the filter by the stage it affected in the earlier installation. Some filters selected recipients, others added data to a template before sending. For add-ons installed in V5, open [Add-ons](/extensions/addons).

Start with the symptom in the old shop. A missing recipient points to selection or blocking. Missing information in a delivered email points to content or template processing.
