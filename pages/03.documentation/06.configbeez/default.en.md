## Choose a setting

These settings apply to every supported shop system. In a hosted MailBeez account, ask [MailBeez Services](https://www.mailbeez.com/about/contact) to change a setting for your shop.

If you run MailBeez on your own server, open **System → Configuration** before testing a campaign. Check the sender customers will see, the service that delivers the email, and the address that receives simulations. A change here can affect several campaigns.

If a test email arrives in the wrong inbox, start with the sending mode. If it arrives with an unfamiliar sender name, check the sender address and profile instead.

Also check that automatic processing is running. The settings you see depend on your permissions and installed modules. To connect an external service, open [Extensions](/extensions).
