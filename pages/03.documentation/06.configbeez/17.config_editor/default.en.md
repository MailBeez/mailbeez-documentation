[doc-callout type="note" title="Earlier MailBeez versions"]
To change the shared email layout in V5, open [Main Templates](/content/main-templates). [Browse the legacy reference](/legacy).
[/doc-callout]

Limit the image browser to the folder your email editors actually use. This can shorten the wait when a shop contains many images.

- **Root for image browser**<br>
  Enter a directory relative to the shop root. Open the browser afterwards and check that the intended images are available.
- **Mobile Editor View Width**<br>
  Choose the width used for the editor’s preview. Change it only to a width supported by your template. A preview setting alone does not make a fixed-width design responsive.
