[doc-callout type="note" title="Frühere Moduleinstellungen"]
Einstellungen in der aktuellen App findest du unter [System](/app-system). [Zur Referenz für ältere Versionen](/legacy).
[/doc-callout]

Fehlt auf einem früheren Dashboard ein Widget, prüfe in der Dashboard-Konfiguration die Auswahl. Öffne anschließend das Dashboard erneut. Die damaligen Widgets findest du unter [Frühere Dashboard-Widgets](/dashboardbeez).

Vergleiche die Widget-Liste mit dem Dashboard derselben Installation. So erkennst du, ob ein Widget ausgeblendet wurde oder im Shop gar nicht installiert ist.
