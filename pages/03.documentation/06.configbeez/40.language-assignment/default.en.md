If customers receive email in an unexpected language, check how the shop assigns a language to their country or order text. Where available, open **System → Configuration → Language & assignment**.

For a multilingual country, check an order whose expected email language you know. The country alone may tell you too little about the language that buyer uses.

1. Choose **Edit**. To find a country, enter its name or ISO code in **Search country or ISO code**.
2. Select the email language. When applying a country preset, review multilingual countries individually. A preset can also affect countries hidden by the current search.
3. Review the changed assignments and save them. Check the corresponding language version of the email template.
