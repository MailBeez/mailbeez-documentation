<span id="display-product-images-in"></span>Change the number of product images and columns in an email’s product grid. The installed module must use the List Engine, and its product-list template must support those settings.

Try a grid with a long product name and with fewer products than a full row. Both cases help you judge whether the chosen column count is readable.

Preview an order with several products after changing either value. If the grid stays the same, check the product-list template the campaign uses.
