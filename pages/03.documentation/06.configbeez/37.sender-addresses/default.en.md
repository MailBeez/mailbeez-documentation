Set the sender your customers should recognize in their inbox, then check where their replies will go. Open **System → Configuration → Sender addresses**.

Send a message to a mailbox you control and reply to it. This checks what buyers see as the sender and which inbox your team actually needs to monitor.

1. Choose **Show Usage** on an existing sender to see which messages use it. Editing a shared sender can affect several mailings.
2. Use **Edit** to update that sender or **New Sender Address** to create a separate identity. Check which sender is marked as the default for newsletters and custom automations.
3. Open a mailing that uses the sender and check the From name and address in a test email. Configure the service that delivers it under [Sending method](/configbeez/config_email_engine).
