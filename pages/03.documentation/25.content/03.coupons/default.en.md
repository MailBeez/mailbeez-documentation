Use a coupon template to set the value and restrictions of a campaign offer. Later, if a buyer says their code didn’t work, ask for the code they received and the day they tried it. You can look up that specific coupon and check its validity.

1. Open **Content → Coupons → Templates** and choose the template that defines the discount.
2. Check its value, restrictions and validity before using it in a campaign.
3. Use **Generated** to look up issued coupons. Use **Series** for batches of codes, for example for offline use. Coupon support depends on the shop system.
