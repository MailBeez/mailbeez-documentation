A roaster runs a live shop and a separate shop where it tests changes to the catalogue. Before connecting SiteZen, decide which one you want to work with and get the token issued for that shop. A token from the test shop won’t confirm a connection to the live one.

## If your account shows the connection settings

Open **System → Extensions → External services** and select **Connect your store to SiteZen**.

[doc-steps]

[doc-step]
**Enter the token for this shop**

Choose **Configure**, paste it into **SiteZen token**, and choose **Save**.
[/doc-step]

[doc-step]
**Check from SiteZen**

Open SiteZen and verify that it can connect to the intended shop. Saving in MailBeez stores the token. If SiteZen cannot reach the shop, check which shop issued the token before replacing it.
[/doc-step]

[/doc-steps]
