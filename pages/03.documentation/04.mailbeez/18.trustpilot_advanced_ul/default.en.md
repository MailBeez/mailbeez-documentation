<span id="why-trustpilot-unique-lin"></span>Use this historical edition only for a Trustpilot account approved for Unique Links. For invitations through the Automatic Feedback Service, see [Ask for reviews on Trustpilot](/mailbeez/trustpilot_advanced).

When maintaining an older template, identify which integration generated its links. The account requirements for this edition also matter if you copy the template to another shop.

1. <span id="multiple-order-status"></span><span id="delay-times-for-internati"></span>Select the order statuses that should start the invitation and allow time for delivery. Orders sent outside the shop’s home country can have a longer delay.
2. <span id="recognition-of-regular-cu"></span>Set the minimum interval between invitations to a repeat buyer. For example, 120 days leaves four months between requests even if the buyer orders more often.
3. <span id="customize-your-invitation"></span><span id="multilingual"></span>Edit the invitation in the MailBeez template. If you use [Multilanguage Extension with Template Manager](/configbeez/config_tmplmngr_lng), match the email language to the Trustpilot page it links to. Check the link in a test email.

<span id="want-to-integrate-your-va"></span>To bring ratings back into the shop, use [Import reviews from Trustpilot](/configbeez/integrations/config_trustpilot_rss_importer).
